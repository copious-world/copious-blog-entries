js-ipfs in Electron

This example is heavily inspired by electron-quick-start.

Before you start

First clone this repo, install dependencies in the project root and build the project.

$ git clone https://github.com/ipfs/js-ipfs.git
$ cd js-ipfs
$ npm install
$ npm run build

Running the example

To try it by yourself, do:

> npm start
